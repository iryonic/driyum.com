## 🚀 **How to Launch**

### Prerequisites
- XAMPP/WAMP/LAMP
- PHP 7.4+
- MySQL 5.7+
- Modern Browser

### Installation Steps
1. **Start Apache & MySQL** from XAMPP Control Panel
2. **Import Database**: `C:\xampp\mysql\bin\mysql.exe -u root -e "source database/schema.sql"`
3. **Access**: `http://localhost/newdry/`

### Default Credentials
```
Admin Email: admin@driyum.com
```
