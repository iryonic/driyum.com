1. PREMIUM AESTHETIC & USER EXPERIENCE (UX)
-------------------------------------------
- Glassmorphism UI: Modern "frosted glass" effects for modals and cards.
- Smooth Micro-Animations: Framer-like transitions for carousels and hovers.
- Infinite Marquee: Continuous brand/announcement loops on desktop & mobile.
- Sticky Smart Header: Blurs background on scroll, adapts for desktop/mobile.
- Bottom Navbar: Native app-like navigation bar for the mobile version.
- Toast Notifications: Real-time feedback for Cart actions and UI events.

2. DYNAMIC CONTENT ENGINE (100% CMS CONTROLLED)
-----------------------------------------------
- Hero Slider: Managed from admin with custom headlines, CTAs, and 3D stickers.
- Live Sale Countdown: Automated timers that hide/show banners based on DB.
- Category Explorer: Scroll-snap category cards with "vibe-based" browsing.
- Featured Drops: Automatic product grids fetching latest arrivals.
- Testimonial "Wall of Love": Cinematic review slider with auto-play.

3. ADVANCED PRODUCT SHOWCASE
----------------------------
- 3D Interactive Gallery: Main image with zoom and decorative floating particles.
- Stock Scarcity Feedback: "Only X Left" or "Sold Out" labels with visual states.
- Benefit Badging: Automated tags like "100% Natural", "Vegan", or "New Drop".
- Dynamic Backgrounds: Product pages automatically tint based on product color.
- Nutritional Information: Dedicated breakdown for high-health products.
- Related Recommendations: Intelligent suggestions based on current category.

4. INTELLIGENT COMMERCE & CHECKOUT ENGINE
-----------------------------------------
- AJAX Cart Sidebar: Add/Remove items and adjust quantities without page reload.
- Real-Time Shipping Logic:
    * Zip-code validation to calculate dynamic shipping rates.
    * Automatic Free Shipping: Triggers "FREE" delivery once threshold (₹499) hit.
    * Multiple Carriers: Users choose between Express and Economy rates.
- Stacking Discount System:
    * Promotional Coupons (Percentage or Flat).
    * Creator/Affiliate Discounts: Auto-apply via URL or referral code.
- Guest Checkout: One-click checkout without the friction of account creation.

5. SECURE PAYMENT INTEGRATION
-----------------------------
- Razorpay Enterprise: Fully integrated with AJAX payment creation.
- Signature Verification: Server-side validation to prevent fraud/fake orders.
- Cash On Delivery (COD): Toggleable support for lower-barrier friction.

6. ORDER LIFECYCLE & TRACKING
-----------------------------
- Public Order Tracking: Check status (Processing -> Shipped -> Delivered).
- Interactive Timeline: Visual progress tracker for customer transparency.
- Digital Invoicing: On-demand PDF/HTML invoice generation for customers.

7. USER PERSONALIZATION
-----------------------
- Personalized Stash: Cross-device persistent Wishlist for logged-in users.
- Saved Addresses: "Magic Checkout" functionality for returning customers.
- Order History: Tabular view of past purchases with re-order capabilities.
- Account Customization: Profile and password management.

8. AFFILIATE & CREATOR ECOSYSTEM
--------------------------------
- Creator Code System: Dedicated discounts for creator audiences.
- Automated Commission Tracking: Records performance in the DB (10% standard).
- Dashboard: (Planned) Visibility for affiliates to see their impact.

9. PERFORMANCE & SEO OPTIMIZATION
---------------------------------
- Gzip Compression: Reduces asset sizes by ~70% via .htaccess.
- Browser Caching: 1-year expiry on static assets for instant repeat loads.
- Native Lazy Loading: Product images load only when in view.
- Asset Prioritization: Hero images use 'fetchpriority=high' to lower LCP.
- Global SEO: Dynamic Title/Meta descriptions per product and category.
- G-Font Pre-connecting: Eliminates font-flicker (FOUT).

10. GLOBAL ACCESSIBILITY (A11y)
-------------------------------
- Screen Reader Ready: ARIA labels on all navigation and icon buttons.
- Descriptive Media: Contextual 'ALT' tags on all product and brand images.
- Focus States: Keyboard-navigable checkout and search interfaces.

11. SECURITY SUITE
------------------
- CSRF Protection: Prevents cross-site request forgery on forms.
- XSS Prevention: Strict input/output sanitization.
- Prepared Statements: Prevents SQL Injection (MySQLi).
- Session Security: Encrypted session management with HttpOnly cookies.

12. ADMINISTRATIVE CONTROL (ADMIN PANEL)
----------------------------------------
- Maintenance Mode: One-click site lockdown with custom maintenance page.
- Settings Control: Change thresholds (Tax, Shipping, SEO) instantly.
- Inventory Manager: Simple controls for stock, prices, and variants.
